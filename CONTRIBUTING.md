# Contributing to [Calculator]

First off, thank you for taking the time to contribute!  It is people like you who make this project better for everyone.

Before you get started, please review the guidelines below to ensure a smooth contribution process.

---

##  Code of Conduct

By participating in this project, you agree to abide by our [CODE OF CONDUCT.md]. Please report any unacceptable behavior to omarchyhyprland@gmail.com.

##  How to Report a Bug

We use GitHub Issues to track bugs. Before creating a new report, please **search existing issues** to make sure it hasn't been reported yet.

When filing a bug report, please include:
- A clear, concise title.
- Steps to reproduce the issue.
- Expected vs. actual behavior.
- Your environment details (OS, language version, SDK version).
- Relevant screenshots or logs if applicable.

##  How to Suggest a Feature

We welcome feature requests! Please open an issue and use the following format:
1. **Problem Statement**: What problem are you trying to solve?
2. **Proposed Solution**: Describe how the new feature should work.
3. **Alternative Solutions**: Any workarounds you have considered.


##  Submission Process (Pull Requests)

To submit your code changes, please adhere to this workflow:

1. Create a new branch from main or development:
   bash
   git checkout -b feature/your-feature-name
   
2. Make your changes. Ensure you write clean code and include matching test coverage.
3. Keep your commit messages brief and descriptive (e.g. feat: add user login validation).
4. Push your branch to your GitHub fork:
   bash
   git push origin feature/your-feature-name
  
5. Open a **Pull Request (PR)** against our main branch.
6. Link your PR to the specific issue it addresses by adding Closes #123 in the description.

##  Code Review Guidelines

Once your PR is submitted:
- At least one core maintainer will review your code.
- Ensure all automated continuous integration (CI) tests pass.
- Address any requested changes or feedback directly in your branch.
- Once approved, a maintainer will merge your PR.

Thank you again for your contribution!
